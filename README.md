# Introduction to Python for Data Science

This repository contains a collection of Jupyter notebooks for an introductory course on Python for data science, developed as part of the AI Academy. The course covers fundamental Python concepts and popular data science libraries like pandas, NumPy, and matplotlib.

## Getting Started

To get started with this course, you will need to set up a Python environment with the required libraries.

### Prerequisites

- Python 3.8 or higher
- `pip` or `conda` for package management

### Installation

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/your-username/intro-to-python.git
    cd intro-to-python
    ```

2.  **Install the required packages:**

    You can install the necessary packages using the `requirements.txt` file:

    ```bash
    pip install -r requirements.txt
    ```

3.  **Launch Jupyter Notebook or JupyterLab:**

    ```bash
    jupyter notebook
    ```
    or
    ```bash
    jupyter lab
    ```

    This will open a new tab in your web browser with the Jupyter interface.

## Repository Structure

The course material is located in the `course/` directory. Here is a brief description of each notebook:

-   **`Data.ipynb`**: Covers Python fundamentals, including data structures, iteration, and a brief introduction to NumPy.
-   **`Files.ipynb`**: Demonstrates how to read from and write to files, including text files, CSVs, and zip files.
-   **`Intro_to_Pandas_and_Series.ipynb`**: Introduces the pandas library, focusing on the `Series` data structure.
-   **`Intro_to_Pandas_DataFrames.ipynb`**: A deeper dive into pandas, focusing on the `DataFrame` data structure.
-   **`Intro_to_Pandas_exercises.ipynb`**: Provides exercises to practice the pandas concepts learned in the previous notebooks.
-   **`Intro_to_matplotlib.ipynb`**: An introduction to data visualization with matplotlib.
-   **`Pandas_for_timeseries.ipynb`**: Focuses on using pandas for time series analysis.

## Usage

Navigate to the `course/` directory in the Jupyter interface and open the notebooks in the recommended order, starting with `Data.ipynb`. It is recommended that you create a new folder for your work to avoid modifying the original course files.
